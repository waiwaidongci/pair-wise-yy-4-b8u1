# 水下考古潜水记录 · 层位编录台

直接打开 `index.html` 使用。水下只记点位，回船后在编录台还原探方与地层关系。

## 功能

- **地图点位**：点击沉船平面图添加遗物标记，支持类型筛选、潜次时间线、编辑、删除与 JSON 导出（原有功能全部保留）。
- **探方档案**：登记探方（名称、位置/水深备注），层位按探方归口管理。
- **层位编录**：登记层号、顶深、底深、直接上层与沉积描述。深度区间重叠、层号重复或上下关系缺失的层位**不进入剖面**，并在“层位判定”中列明原因。
- **地层剖面**：确认层位按顶深自动排序编号；改动顶底深度或上下关系后，后续层位自动重排。遗物只能归到已确认层位，层位失效的遗物会被显式标出。
- **发布管理**：剖面发布后数值锁定，编录改动不会静默写入；界面列出受影响层位（深度/关系/序次/描述变更、新增、退出）和受影响遗物，确认后重新发布。

## 文件结构

- `stratigraphy.js` — 层位判定：校验、剖面生成、发布影响计算（纯逻辑）
- `archive.js` — 探方档案：探方、层位、遗物与发布快照的登记和持久化
- `app.js` — 页面：地图、表单、列表与编录台交互
- `index.html` — 页面结构

数据保存在浏览器 localStorage（遗物沿用原键 `zfl30Marks`，旧数据可直接使用）。
