# 水下考古层位编录台

潜水时只记点位与深度，回船后补全探方、层位与地层关系。直接用浏览器打开 `index.html`
（或 `python3 -m http.server` 后访问），数据保存在浏览器 localStorage。

## 三个业务文件

- `index.html` — 页面：地图点位、层位编录、探方档案三个视图。
- `strata.js` — 层位判定（纯逻辑）：层号重复、深度区间重叠、上下接触缺失校验，
  确认剖面排序，遗物按深度归层，已发布剖面差异计算。
- `archive.js` — 探方档案：探方/层位/遗物数据、持久化、发布快照、JSON 导出。
  首次打开自动把旧版 `zfl30Marks` 标记迁入 T1 探方并按深度归层。

## 使用规则

- 层位登记层号、顶深、底深、沉积描述。层号重复、顶底深度区间重叠（相接不算）、
  或与上下层之间存在间隔（接触关系缺失）的层位**不进入确认剖面**，问题逐条标红。
- 遗物只能归属到本探方的已确认层位；改动约深或地层关系后，确认剖面重新排序，
  失归属的遗物按深度重新匹配，无法落层的保持“未归属”。
- 「发布剖面」冻结当前层号、顶底深度、沉积描述、位次与遗物归属。发布后再改值不会
  静默覆盖：右侧“受影响层位与遗物”列出新增、退出、改值（旧值→新值）、位次变化
  及受影响的每件遗物；重新发布需确认。
- 地图布点、类型/层位过滤、潜次时间线、JSON 导出沿用原功能，导出含全部探方档案。
